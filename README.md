# Goulu

Page de téléchargement de **Goulu**, l'appli Android qui planifie tes repas, tes courses et ta santé.

👉 https://lucasaw2.github.io/goulu/

Les fichiers de l'appli (APK) sont publiés sur [MealPlanner-releases](https://github.com/Lucasaw2/MealPlanner-releases/releases/latest).
Cette page est générée depuis le code de l'appli (`npm run site`) : ne pas la modifier ici à la main.
